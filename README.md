# LangChain Learning Roadmap

A Python-focused learning package based on the current official [LangChain documentation](https://docs.langchain.com/).

## Downloads

- [LangChain Staged Learning Roadmap](./LangChain_Staged_Roadmap_Python.pdf) — an eight-stage, project-led path from a first tool-calling agent to a tested and deployable system.
- [LangChain Concepts Handbook](./LangChain_Concepts_Handbook_Python.pdf) — simple explanations, mental models, mini-exercises, and links to official documentation.

## What is covered

- LangChain models, messages, tools, agents, and structured output
- Short-term and long-term memory
- Context engineering, middleware, streaming, and guardrails
- Retrieval-augmented generation (RAG)
- LangGraph state, nodes, edges, persistence, checkpoints, and interrupts
- Human-in-the-loop workflows
- Multi-agent patterns and Deep Agents
- LangSmith tracing, evaluation, deployment, and monitoring

The roadmap uses one evolving **Support Desk Copilot** capstone and follows an approximate **30% study / 70% implementation** split.
